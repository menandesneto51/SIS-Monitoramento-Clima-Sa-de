# Buscar no Catálogo Mestre SES-MT

```powershell
.\scripts\catalogo-ses.ps1 -Query "<necessidade de dados>"
```

Retorne fontes, objetos, campos, sensibilidade/PII, catalog_health, ranking, limitações e próximo passo. Não crie nova fonte quando o catálogo já contiver o dado; se houver inventário partial/missing, atualize-o antes de concluir ausência.
